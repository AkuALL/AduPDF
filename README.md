# PPK_Kel1
Repository untuk tugas besar PPK Kelas B
Kelompok 1

How to run locally:
Di lokal directory, via terminal, run:
1. git clone https://github.com/AkuALL/AduPDF.git
2. cd Adupdf/
3. npm install
4. composer install
5. <setup .env at project's root directory>
5. php artisan key:generate
6. php artisan migrate --seed
7. composer run dev
